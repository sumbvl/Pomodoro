Pomodoro Timer with Daily History
A lightweight, single screen Pomodoro timer built as a responsive web application. 

Features:
- Visual State Management: Clean typography layouts outlining focus sessions and breaks
- Configurable Intervals: Adjustable inputs for custom focus and break intervals
- Responsive Interface: Designed to match viewport scaling across desktop and mobile browsers

Tech Stack:
- HTML5
- CSS3 (Inline Styling)

How to Run:
Local Setup
No compilation, bundling, or local server installation is required. 
or Clone this repository to your local machine: (and then navigate into the project folder.
Open pomodoro.html directly in any web browser.)
