Question 1
Just download or clone the repo and open the pomodoro.html file in your browser.
You don't need to install anything or run any local servers to see it.

Question 2
I'm still pretty new to web development and mostly just know the basics of HTML and inline CSS, so I stuck with what I know to design the layout.
I decided to center everything and make the timer text huge so it's the first thing you look at.

Question 3
Right now, it's really not optimized for mobile. I used basic percentages to keep stuff centered, but it looks best on a normal desktop or laptop screen.
I also skipped accessibility stuff like keyboard shortcuts or screen reader labels since it's just a simple static layout for now.

Question 4
I used AI to help me clean up my HTML inputs and figure out the best way to lay out the page.

Question 5
The most obvious gap is that the app doesn't actually work yet. Since there isn't any JavaScript behind it, the timer doesn't tick down and the history section doesn't actually log anything. It's just a visual mockup.
If I had more time, I would write the JavaScript to make the countdown work and add media queries so the layout doesn't break on a phone screen.
